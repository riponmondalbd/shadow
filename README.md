## 🇺🇸 English Version

MyShadow is a professional, Zero-Knowledge personal data vault with an intelligent In-page Mini-Vault extension for your browser. It allows you to securely auto-fill usernames and passwords across websites effortlessly.

### ✨ Features
- **Zero-Knowledge Security:** Your data remains securely encrypted.
- **Intelligent In-page Mini-Vault:** Automatically detects input fields and displays a sleek shield icon.
- **Seamless Auto-Fill:** Easily auto-fill usernames and passwords inside input fields with a click.
- **Customizable:** Can be toggled on/off to suit your workflow.

### 🚀 Installation Guide

#### Loading the Extension in Chrome
1. Download or clone this repository to your local machine.
2. Open Google Chrome and go to `chrome://extensions/`.
3. Enable **Developer mode** in the top right corner.
4. Click on **Load unpacked** and select the folder containing the extension files.
5. The **MyShadow** extension should now appear in your list of extensions. Pin it to your toolbar for easy access!

### 💻 How to Use
1. **Navigate to any website** with a login form.
2. Click on the username or password input field.
3. You will see a small **Shield Icon** appear inside the input field.
4. Click the shield icon to open the Mini-Vault popup right on the page.
5. Select the credential you want to use, and MyShadow will magically auto-fill the details for you!

### ⚙️ Configuration
The extension integrates securely with your central vault application. Ensure your vault is set up and unlocked to seamlessly sync your credentials to the extension.

## 🇧🇩 বাংলা সংস্করণ (Bengali Version)

মাইশ্যাডো (MyShadow) হলো একটি প্রফেশনাল, জিরো-নলেজ ব্যক্তিগত ডেটা ভল্ট, যার সাথে রয়েছে একটি ইনটেলিজেন্ট ইন-পেইজ মিনি-ভল্ট ব্রাউজার এক্সটেনশন। এর মাধ্যমে আপনি খুব সহজেই বিভিন্ন ওয়েবসাইটে আপনার ইউজারনেম এবং পাসওয়ার্ড নিরাপদে অটো-ফিল (Auto-fill) করতে পারবেন।

### ✨ মূল ফিচারসমূহ
- **জিরো-নলেজ সিকিউরিটি:** আপনার ডেটা সবসময় সম্পূর্ণ সুরক্ষিত ও এনক্রিপ্টেড থাকে।
- **ইনটেলিজেন্ট ইন-পেইজ মিনি-ভল্ট:** স্বয়ংক্রিয়ভাবে ইনপুট ফিল্ড শনাক্ত করে এবং একটি সুন্দর শিল্ড (Shield) আইকন প্রদর্শন করে।
- **সহজ অটো-ফিল:** মাত্র এক ক্লিকেই ইনপুট ফিল্ডে ইউজারনেম এবং পাসওয়ার্ড অটো-ফিল করার সুবিধা।
- **কাস্টমাইজযোগ্য:** প্রয়োজন অনুযায়ী এক্সটেনশনের সুবিধাটি চালু বা বন্ধ (Toggle) করা যায়।

### 🚀 ইনস্টলেশন গাইড (কীভাবে ইনস্টল করবেন)

#### ক্রোম (Chrome) ব্রাউজারে এক্সটেনশন যুক্ত করার নিয়ম:
১. এই রিপোজিটরিটি আপনার কম্পিউটারে ডাউনলোড বা ক্লোন করুন।
২. গুগল ক্রোম ওপেন করে অ্যাড্রেস বারে `chrome://extensions/` লিখে এন্টারে চাপ দিন।
৩. উপরের ডান দিকের কোণায় থাকা **Developer mode** অপশনটি চালু (Enable) করুন।
৪. এবার **Load unpacked** বাটনে ক্লিক করুন এবং এক্সটেনশন ফাইলের ফোল্ডারটি (যেখানে ফাইলগুলো আনজিপ করা আছে) নির্বাচন করুন।
৫. আপনার এক্সটেনশন লিস্টে **MyShadow** যুক্ত হয়ে যাবে। সহজে ব্যবহার করার জন্য এটি টুলবারে পিন (Pin) করে রাখুন!

### 💻 ব্যবহারের নিয়ম (কীভাবে ব্যবহার করবেন)
১. লগইন ফর্ম আছে এমন **যেকোনো ওয়েবসাইটে** যান।
২. ইউজারনেম বা পাসওয়ার্ডের ইনপুট ফিল্ডে ক্লিক করুন।
৩. আপনি ইনপুট ফিল্ডের ভেতরে ছোট একটি **শিল্ড আইকন (Shield Icon)** দেখতে পাবেন।
৪. শিল্ড আইকনে ক্লিক করলে পেইজেই মিনি-ভল্ট পপআপ ওপেন হবে।
৫. আপনার কাঙ্ক্ষিত ক্রেডেনশিয়াল (লগইন তথ্য) নির্বাচন করুন এবং মাইশ্যাডো স্বয়ংক্রিয়ভাবে আপনার বিস্তারিত তথ্য অটো-ফিল করে দিবে!

### ⚙️ কনফিগারেশন
এই এক্সটেনশনটি আপনার কেন্দ্রীয় ভল্ট অ্যাপ্লিকেশনের সাথে নিরাপদে যুক্ত থাকে। এক্সটেনশনে আপনার ক্রেডেনশিয়াল সিঙ্ক করার জন্য আপনার ভল্ট সেটআপ এবং আনলক করা আছে কিনা তা নিশ্চিত করুন।
